# Uliczny Absurd

Rozbudowany sklep Next.js + React + TypeScript, PostgreSQL, panel administratora, pobranie i opcjonalny Stripe. Zachowany projekt wizualny wejściowej strony.

**Najpierw przeczytaj `START-TUTAJ.md`.** Wymagana konfiguracja bazy; domyślny tryb TEST nie realizuje zakupów. Sekrety wyłącznie w środowisku. Fizyczne stany oraz ceny nieznanych produktów wymagają uzupełnienia.

- `npm ci`, `npm run db:setup`, `npm run dev`
- `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`
- Instrukcja prawna i źródła: `docs/LEGAL.md`
- Wyniki testów i granice sprawdzenia: `docs/TESTY.md`
- Architektura i utrzymanie: `docs/BACKEND.md`

Nie publikowano na GitHubie ani Vercel w ramach przygotowania plików.
